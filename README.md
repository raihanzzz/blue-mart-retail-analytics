# BlueMart – Retail Sales Data Analytics

An exploratory data analysis project focused on understanding retail sales performance, customer behaviour, product trends, store performance, promotions, and inventory using Python.

## Project Overview

This project analyzes BlueMart's retail business data to uncover meaningful insights and identify patterns that can support better business and operational decisions.

Using Python and its data analysis libraries, the project explores sales performance, customer activity, product profitability, promotional trends, and inventory-related metrics.

## Dataset Description

The project uses six datasets:

| Dataset | Description |
|---|---|
| `bm_customers` | Customer-related information |
| `bm_inventory` | Product inventory details |
| `bm_promotions` | Promotional campaign information |
| `bm_sales` | Retail sales transaction records |
| `bm_skus` | Product and SKU details |
| `bm_stores` | Store-related information |

## Tools & Technologies

- **Python** – Primary programming language
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical data visualization
- **Jupyter Notebook** – Analysis environment

## Key Areas of Analysis

- Sales performance and revenue trends
- Product and category performance
- Customer behaviour and purchasing patterns
- Store-wise sales performance
- Promotion-related analysis
- Product profitability
- Inventory analysis and stock risk identification

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/retail-sales-data-analytics.git
```

### 2. Navigate to the project directory

```bash
cd retail-sales-data-analytics
```

### 3. Install dependencies

```bash
pip install pandas numpy matplotlib seaborn jupyter openpyxl
```

### 4. Run the notebook

```bash
jupyter notebook Blu-Mart.ipynb
```

The objective is to transform raw retail data into meaningful business insights through data cleaning, exploratory data analysis, data visualization, and analytical techniques.
